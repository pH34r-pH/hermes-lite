# hermes-lite — retired

This repository is permanently abandoned and retained only as historical source.

**Pi is the sole supported agent harness for this project family.** No further development, releases, compatibility work, security fixes, or migration support will be provided here. Do not use `hermes-lite` as a dependency or deployment target.

Nacre Recall is being redesigned as a Pi-native, Long-Haul-supporting recall and continuity component. Long-Haul remains authoritative for crew identity, missions, work contracts, checkpoints, policy, execution evidence, and acceptance; Nacre provides only bounded, provenance-bearing recall and review-gated memory proposals.

Historical contents below this commit are not a supported product surface.
